# Leap Widget 0.1.1

## Fixes

- **The year is right across December and January.** In December, a Two Months
  widget with Second Month set to Next showed January with the current year, for
  example "JANUARY ’26" for January 2027. Now each month in a December–January
  row gets its own year label. The current month's year is in the accent color.
  The other year is grey, like the week numbers. This works with Second Month
  set to Next and to Previous. Rows within one year still have a single year
  label.
- **Today moves to the new day at midnight.** The widget now asks the system to reload at
  the first midnight, so the desktop widget updates when the day changes.
  Midnight is also handled correctly on days when daylight saving time skips
  00:00.
- **Widget settings show readable names.** The widget's Edit Widget menus showed
  internal values in place of option names. They now show readable names.
  Widgets that are already set up keep their settings.

## Documentation

- **New README.** The README is now a page for users: the pitch, a screenshot
  and the install command come first. It says the app is free, open source
  (MIT) and shows dates, not events. A "Privacy you can check" section links to
  the files behind each privacy claim. Developer docs moved to
  `CONTRIBUTING.md`.
