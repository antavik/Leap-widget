# Manual screenshots

Every image the manual references lives here. Until a real capture replaces it,
the file is missing on purpose and the page shows a broken image - the HTML
comment next to each reference says what the shot has to contain.

## Capture rules

- Retina (2x) PNG, captured on a Mac running the minimum supported macOS.
- Light appearance unless the shot is about dark mode.
- Default wallpaper; no personal data, no visible names, no other apps' windows.
- Window shots: Command-Shift-4 then Space, which keeps the rounded corners and
  the shadow.
- Crop widget shots tight to the widget plus a little wallpaper.
- Keep the file name exactly as listed; the manual and its Help Book build
  reference it by name.
